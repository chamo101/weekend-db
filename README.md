# 休着 · 双休公司信息库 (weekend-db)

> 按**城市**查询国内公司的**双休情况**和**请假难度**。数据来自公开报道与社区贡献，持续更新。

🌐 **在线查询**：GitHub Pages 将在仓库创建后自动部署（见下方说明）

## 为什么做这个

- 找工作/换工作时，"这家公司双休吗？"是刚需问题，但信息散落在脉脉、看准、小红书各处，没有结构化的数据库
- **同一家公司不同城市、不同部门的双休落实情况可能完全不同**——大公司总部的政策不代表你所在的分部。所以本库以「公司 × 城市」为最小记录单位

## 数据说明

| 字段 | 说明 |
|---|---|
| company | 公司名称 |
| city | 所在城市（多城市用 `/` 分隔） |
| district | 区/园区（可选，更精确） |
| industry | 行业 |
| size | 规模：大厂 / 中厂 / 小厂 |
| **weekend_type** | **双休 / 大小周 / 单休 / 上四休三**（核心字段 1） |
| **leave_difficulty** | **请假难度**（核心字段 2：宽松 / 一般 / 难） |
| overtime_status | 加班情况补充说明 |
| source_type | 来源类型：官方/媒体公开报道 / 企业信息平台 / 社区贡献 |
| source_url | 来源链接 |
| last_verified | 最后核实时间 (YYYY-MM) |
| notes | 备注 |

核心数据文件：[`data/companies.csv`](data/companies.csv)

## 如何补充 / 更新数据（三选一）

1. **📝 腾讯文档共建表**（推荐，无需懂技术，手机可操作）：
   👉 **https://docs.qq.com/smartsheet/DSUZrY0JlblpjbE96**
   已设为**公开可编辑**：打开即可直接添加/修改记录（表头与 CSV 字段一致，下拉选择休息制度/请假难度/规模）。
   维护者定期把共建表新数据合入本仓库 CSV。
2. **GitHub Issue**：[新建 Issue](../../issues/new) 用模板填写
3. **直接提 PR**：修改 `data/companies.csv`，一行一条记录，提交即可

⚠️ 请提供来源（新闻链接、招聘页截图说明等）。纯个人感受也欢迎，但会标注为「社区贡献 · 待核实」。

## 免责声明

数据仅供参考。同公司不同城市/部门/时期执行情况可能不同，**入职前请务必在面试中与 HR 或在职员工核实**。本项目与任何公司无关，不接受删帖请求，但欢迎提供更正依据，我们会核实后更新。
